# AI-Tools-Usage-And-Productivity-Analysis

Project Summary

Analyze a real-world dataset of 30,000 employee records to understand how AI tools are being adopted across different industries and job roles.
Perform data cleaning and preprocessing, including handling missing values, checking duplicates, converting data types, and detecting outliers.
Conduct Exploratory Data Analysis (EDA) using NumPy, Pandas, Matplotlib, and Seaborn to discover patterns and relationships within the data.
Evaluate the impact of AI tool usage on employee productivity, salary, job satisfaction, and career growth.
Compare AI adoption across industries, company sizes, work modes (remote/on-site), and experience levels.
Answer 20+ business-driven analytical questions using statistical analysis and effective visualizations.
Generate actionable insights and recommendations to help organizations understand the benefits and trends of AI adoption in the workplace.
Present findings in a well-structured, reproducible Jupyter Notebook with clear visualizations, interpretations, and conclusions suitable for academic evaluation and a professional data analytics portfolio.
